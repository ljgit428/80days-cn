# 技术笔记（不含游戏文本与译文）

## 游戏结构
- GOG 版 80 Days：Unity 5 / Mono。游戏逻辑在 `80 Days_Data\Managed\Assembly-CSharp.dll`。
- 文本集中在 `resources.assets` 的若干 TextAsset：剧情剧本 `80days.inkcontent`（JSON Lines，每行一个容器）、
  索引 `80days`（buildingBlocks 与每行的字节偏移 ranges）、数据文件 mapdata / itemsdata / cast / facts / chaptertitles。
- 改写 inkcontent 后必须按新的字节长度重建 `80days` 里的 ranges，否则跳转错位。

## 字体
- 原字体 Lato 无中文。把 Noto Sans SC 设为 TextMeshPro 字体资源的 fallback（sharedassets0/1），并把动态字体数据替换为中文字体实例。
- UnityPy 读不到无 typetree 的 MonoBehaviour 时，用 TypeTreeGeneratorAPI 从 Managed 目录生成 typetree；
  关卡文件必须在游戏目录里加载，否则依赖缺失。

## 中文排版（CNText.dll，经 Mono.Cecil 注入）
- 原排版按空格拆词逐词动画：替换 `string.Split` 为按 CJK 字符拆分，CJK 边界词间距为 0，渐显速度按字数调整。
- 剧情由片段拼接而成，会出现“！。”“，，”等重复标点：在 `TextMarkup.CorrectSpacingAndPunctuation` 返回值上做合并。
- 程序拼句（线索、日期、金钱、行李提示）结果统一过一遍：去中文旁空格、半角标点转全角。
- 线索句由程序按英文语法拼装，中文需要重写生成逻辑（按城市 / 路线 / 物品等类别输出中文句式）。

## 程序内字符串
- 用 Mono.Cecil 遍历所有方法的 `ldstr`，按“类型::方法 → 原文 → 译文”的表替换；标识符、存档键、动画名、统计事件名不能改。
- 数字转英文单词的函数直接改成输出阿拉伯数字。

## 发布
- 不分发游戏文件：用 xdelta3 对“原版 → 汉化后”做差异补丁，安装时先校验 MD5，备份原版后再打补丁。
